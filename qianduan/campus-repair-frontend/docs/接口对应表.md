# 页面与后端接口对应表

本表依据前后端交接包 v1.0。接口路径均包含 `/api`，前端统一通过本地开发代理发起请求。除登录与健康检查外，请求附带 Bearer token。工单 ID、用户 ID 一律按字符串处理。

| 页面或操作 | 方法与接口 | 使用角色 | 实现文件 |
| --- | --- | --- | --- |
| 登录 | `POST /api/auth/login` | 公开 | `src/views/LoginView.vue` |
| 报修表单选项 | `GET /api/meta/order-options` | 学生；统计页管理员 | `src/views/CreateOrderView.vue`、`StatisticsView.vue` |
| 上传现场图片 | `POST /api/uploads/images` | 学生 | `src/views/CreateOrderView.vue` |
| 提交报修 | `POST /api/orders`，带 `Idempotency-Key` | 学生 | `src/views/CreateOrderView.vue` |
| 我的报修 | `GET /api/orders/my` | 学生 | `src/views/StudentOrdersView.vue` |
| 我的维修工单 | `GET /api/orders/assigned-to-me` | 维修工 | `src/views/StudentOrdersView.vue` |
| 待派工单 | `GET /api/orders/pending` | 管理员 | `src/views/AdminOrdersView.vue` |
| 当前／历史超时 | `GET /api/orders/overtime` | 管理员 | `src/views/AdminOrdersView.vue` |
| 工单详情 | `GET /api/orders/{id}` | 有权访问工单的角色 | `src/views/StudentDetailView.vue`、`AdminDetailView.vue` |
| 处理日志 | `GET /api/orders/{id}/logs` | 有权访问工单的角色 | 同上 |
| 现场图片 | `GET /api/uploads/images/{studentId}/{filename}` | 有权访问图片的角色 | 同上；以鉴权请求获取 Blob |
| 可选维修工 | `GET /api/workers/available` | 管理员 | `src/views/AdminDetailView.vue`、`EvaluationsView.vue` |
| 派单／改派 | `POST /api/orders/{id}/assign` | 管理员 | `src/views/AdminDetailView.vue` |
| 取消 | `POST /api/orders/{id}/cancel` | 学生或管理员，受状态限制 | `src/views/StudentDetailView.vue`、`AdminDetailView.vue` |
| 接单 | `POST /api/orders/{id}/accept` | 当前维修工 | `src/views/StudentDetailView.vue` |
| 提交维修结果 | `POST /api/orders/{id}/finish` | 当前维修工 | `src/views/StudentDetailView.vue` |
| 确认／驳回 | `POST /api/orders/{id}/confirm`、`/reject` | 报修学生 | `src/views/StudentDetailView.vue` |
| 评价 | `POST /api/orders/{id}/evaluate` | 报修学生 | `src/views/StudentDetailView.vue` |
| 评价汇总 | `GET /api/stats/evaluations` | 管理员 | `src/views/EvaluationsView.vue` |
| 工单统计 | `GET /api/stats/orders` | 管理员 | `src/views/StatisticsView.vue` |

请求和错误处理在 `src/api.ts` 统一封装。状态修改请求附带详情返回的 `version`；409 时刷新详情并保留输入，由用户决定是否重新提交。报修创建的同一次失败重试使用原幂等键和原表单快照。页面操作按钮仅改善体验，权限由后端最终验证。
