# 校园报修系统前端

前端开发工程。接口基址通过 Vite 代理连接本机后端 `http://127.0.0.1:5000`；脚本、样式和组件由本地项目提供，不依赖 CDN。

## 启动

1. 后端位于工作区根目录的 `houduan`，从本工程出发是 `../../houduan`。在后端目录运行 `./scripts/start_backend.ps1`，保持该终端打开。访问 `http://127.0.0.1:5000/api/health/ready`，确认返回 `status=ready`。
2. 首次运行在本目录执行 `npm ci`；随后运行 `npm run dev`。
3. 在本机 Chrome 或 Edge 打开 `http://127.0.0.1:5173`。不要通过 `file://` 打开。

演示账号与密码见相邻交接资料 `校园报修系统_前后端交接包_v1.0/frontend/前后端交接说明.md` 第 1 节。演示库最初没有工单，请先以学生账号提交，再使用管理员、维修工账号处理。

## 命令

- `npm run dev`：启动开发服务。
- `npm run check`：执行 TypeScript/Vue 类型检查。
- `npm run build`：生成 `dist` 文件。构建后的文件不引用 CDN；仍需可访问的本机 API 才能完成业务操作。
- `npm run preview`：在 `http://127.0.0.1:4173` 预览构建页面，已显式配置 `/api` 代理到后端。

开发时使用5173端口。构建后，后端已接入本工程 dist/index.html 和 dist/assets，可直接访问 `http://127.0.0.1:5000` 使用同源页面，不需另开前端服务。先运行 npm run build，再启动或重启后端。前端使用 Hash 路由，刷新地址中的 #/ 路由仍访问根页面；未知 API 仍返回 JSON 404，不回退到网页。

第八步核心浏览器流程已验证：学生提交、管理员派单/改派、维修工接单/完成、学生驳回/再次完成/确认/评价、图片显示、取消、双窗口版本冲突。全部验收状态及仍待检查事项见 docs/验收记录.md。

接口与页面关系见 [接口对应表](docs/接口对应表.md)；可复核的验证状态、浏览器验收步骤和已知限制见 [验收记录](docs/验收记录.md)。接口契约以相邻的 `校园报修系统_前后端交接包_v1.0/frontend` 为准。
