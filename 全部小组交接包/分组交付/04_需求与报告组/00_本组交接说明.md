# 需求与报告组交接说明

交付方：A2 系统设计与数据库负责人。版本：A2 修订稿 0.2；分组日期：2026-10-12。本包已包含本组必读内容与必要参考文件，解压后从本说明开始。

## 阅读顺序

1. [review-and-tasks.md](review-and-tasks.md)：优先处理待小组确认的规则与本次修订。
2. [system-design.md](system-design.md)：用于整理数据库和系统设计章节。
3. [diagrams/README.md](diagrams/README.md)：选择七张 SVG 插入报告，保留 Mermaid 源码。
4. [acceptance.md](acceptance.md)：补全需求追踪与验收章节。
5. [verification-report.md](verification-report.md)：准确表述当前验证结果。

## 本组任务

- 组织确认 SLA 起止点和时长、故障分类、推荐权重、token 有效期及站内提示范围。
- 记录每项规则的最终决定、确认人和日期，再交 A2 同步到设计与接口。
- 将数据字典、E-R 图、类图、状态图和四张时序图整理进课程报告。
- 报告中区分原说明书要求、A2 设计建议、已经验证的 SQL 和尚待实现的应用功能。
- 与测试组核对需求追踪矩阵及验收结果，与前后端核对最终交付版本。

## 完成标准

关键业务取值有明确结论；正文、图、字段与接口一致；报告不将数据库验证写成系统已经全部验收。

## 需要回交给 A2 的内容

- 业务规则确认记录及仍未决定的问题。
- 报告或设计说明书的整合稿，以及插图编号与说明。
- 最终评审意见、需求版本与交付清单。

## 统一版本约定

SLA 建议 4/24/72 小时、故障分类、推荐权重和 token 有效期均需小组确认。各组汇总修改意见，由 A2 更新统一基线后重新分发。说明中没有写成通过的测试均需实际执行。

Markdown 文件用于阅读设计与说明；SVG 是图稿；Mermaid 是图源。SQL 和数据库验证脚本随后端、测试包提供。分组复制保留原文件名，以保证文档链接和验证脚本可用。
