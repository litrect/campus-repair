# 前端开发组交接说明

交付方：A2 系统设计与数据库负责人。版本：A2 修订稿 0.2；分组日期：2026-10-12。本包已包含本组必读内容与必要参考文件，解压后从本说明开始。

## 阅读顺序

1. [api-contract.md](api-contract.md)：先按接口字段、分页结构、错误码和图片流程对接。
2. [diagrams/README.md](diagrams/README.md)：按状态图和四张时序图安排页面操作。
3. [acceptance.md](acceptance.md)：核对表单、权限、提示和页面验收项。
4. [system-design.md](system-design.md)：查阅角色和字段含义。

## 本组任务

- 完成学生报修、我的报修、详情、确认驳回和评价页面。
- 完成维修工列表、接单和填写维修结果页面，以及管理员待派、派单、超时和统计页面。
- 同一次提交及网络重试保留 Idempotency-Key；新表单提交生成新键。
- 保留服务端返回的 version，修改请求带上它；409 时提示刷新。所有 BIGINT ID 按字符串处理。
- 故障分类从 meta 接口读取；状态决定可见操作；登录身份与工单归属仍由后端验证。
- 落实图片上传、带鉴权头获取图片、列表轮询提示和本地前端依赖，完成断网演示。

## 完成标准

四个主流程可通过页面走通；必填校验、加载反馈和失败提示清楚；幂等键、version、字符串 ID 与后端约定一致。

## 需要回交给 A2 的内容

- 页面代码版本、页面与接口对应清单、启动步骤。
- 学生、维修工、管理员核心流程截图或演示录屏。
- Chrome/Edge 及手机尺寸的检查记录、联调问题清单。

## 统一版本约定

SLA 建议 4/24/72 小时、故障分类、推荐权重和 token 有效期均需小组确认。各组汇总修改意见，由 A2 更新统一基线后重新分发。说明中没有写成通过的测试均需实际执行。

Markdown 文件用于阅读设计与说明；SVG 是图稿；Mermaid 是图源。SQL 和数据库验证脚本随后端、测试包提供。分组复制保留原文件名，以保证文档链接和验证脚本可用。
