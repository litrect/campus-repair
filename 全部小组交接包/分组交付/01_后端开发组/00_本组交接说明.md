# 后端开发组交接说明

交付方：A2 系统设计与数据库负责人。版本：A2 修订稿 0.2；分组日期：2026-10-12。本包已包含本组必读内容与必要参考文件，解压后从本说明开始。

## 阅读顺序

1. [implementation-notes.md](implementation-notes.md)：先确认统一状态入口、事务、幂等和超时算法。
2. [api-contract.md](api-contract.md)：按请求、响应、权限和错误码实现接口。
3. [schema.sql](schema.sql)：在新库执行建表脚本。
4. [seed.sql](seed.sql)：按需导入本机演示账号。
5. [system-design.md](system-design.md)：核对数据字典和状态迁移。

## 本组任务

- 按四表模型实现数据访问层，使用参数化 SQL。
- 实现登录、角色与工单归属校验，以及接口契约中的后端能力。
- 所有已有工单更新通过统一业务入口，以客户端版本做条件更新；工单与日志同事务。
- 落实创建幂等、改派前后维修工记录、评价唯一性、业务动作与定时扫描共同结算超时。
- 与前端确认接口字段、错误提示、图片上传和鉴权读取；向测试组提供可运行环境。

## 完成标准

数据库脚本执行成功；正常流程、驳回、取消、改派均可完成；并发冲突和日志失败回滚可复现。完整验收采用 acceptance.md。

## 需要回交给 A2 的内容

- 代码版本或提交号、启动方式、配置项和依赖说明。
- 目标环境 SQL 执行结果，以及实际复现的数据库验证报告。
- 接口联调结果、未实现功能和仍待业务确认的问题。

## 统一版本约定

SLA 建议 4/24/72 小时、故障分类、推荐权重和 token 有效期均需小组确认。各组汇总修改意见，由 A2 更新统一基线后重新分发。说明中没有写成通过的测试均需实际执行。

Markdown 文件用于阅读设计与说明；SVG 是图稿；Mermaid 是图源。SQL 和数据库验证脚本随后端、测试包提供。分组复制保留原文件名，以保证文档链接和验证脚本可用。
