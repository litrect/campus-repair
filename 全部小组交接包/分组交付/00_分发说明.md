# 小组文件分发说明

版本：A2 修订稿 0.2。按职责划分为四个组；若实际组织将前后端合为技术实现组，将两个开发包一起交给该组即可。

| 接收对象 | 开始阅读 | 主要用途 |
| --- | --- | --- |
| 后端开发组 | [本组交接说明](01_后端开发组/00_本组交接说明.md) | 按四表模型实现数据访问层，使用参数化 SQL。 |
| 前端开发组 | [本组交接说明](02_前端开发组/00_本组交接说明.md) | 完成学生报修、我的报修、详情、确认驳回和评价页面。 |
| 测试与质量组 | [本组交接说明](03_测试与质量组/00_本组交接说明.md) | 建立三个角色的测试账号和可重复使用的工单数据，记录环境与后端版本。 |
| 需求与报告组 | [本组交接说明](04_需求与报告组/00_本组交接说明.md) | 组织确认 SLA 起止点和时长、故障分类、推荐权重、token 有效期及站内提示范围。 |
| A2 自己留存 | [总交付说明](05_A2总交付留存/README.md) | 保存完整基线、核验结果和全部图源。 |

## 如何发给组员

1. 在旁边的“小组交接压缩包”目录找到对应组名的 ZIP。
2. 将 ZIP 发送给该组负责人，请其解压后先读 `00_本组交接说明.md`。
3. 按交接说明中的任务和完成标准开展工作，并把结果回交 A2。
4. A2 保存总交付留存包，统一整理修改意见，冻结后再发新版。

本次只完成本地分类和压缩，尚未通过聊天工具或邮箱发送给任何组员。
