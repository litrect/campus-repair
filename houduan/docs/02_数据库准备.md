## 环境就绪后的执行方式

在“houduan”目录，使用实际 MySQL 客户端路径及本机连接参数：

```powershell
.\scripts\init_database.ps1 -Mysql 'C:\实际安装位置\bin\mysql.exe' -DbHost 127.0.0.1 -Port 3306 -User root
python .\scripts\verify_delivery.py --mysql 'C:\实际安装位置\bin\mysql.exe' --host 127.0.0.1 --port 3306 --user root --database a2_verify_20261015 --report .\docs\database-verification-results.json
```

密码通过当前进程 MYSQL_PWD 提供，不写入命令参数或版本管理；不要在聊天中发送密码。验证库名每次使用新值。脚本不自动删除数据库，DDL 可能隐式提交，失败后先检查已创建对象再用新库重试。

演示库默认为 campus_repair；如已存在，初始化脚本通过 -Database 指定其他新库。程序后续配置必须使用最终实际建成的数据库名。
