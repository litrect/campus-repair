## 如何运行

```powershell
# 在工作区根目录
cd .\qianduan\campus-repair-frontend
npm run build
cd ..\..\houduan
.\scripts\start_backend.ps1
```

访问 http://127.0.0.1:5000。日常开发也可在前端目录 npm run dev 后访问5173；preview为4173。依赖初次安装用 npm ci，须保留package-lock.json。依赖安装后运行核心业务不需要外网。
