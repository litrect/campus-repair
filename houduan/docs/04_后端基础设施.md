# 步骤 3：后端基础设施

日期：2026-10-15。项目根目录：houduan。

## 已实现

- Python 3.12.14 独立环境 .venv，已安装依赖，requirements.txt 锁定实际版本。
- Flask 应用工厂；api → services → repositories → MySQL 分层。
- 配置优先级：进程环境变量 > 根目录 .env > instance/mysql-local.json 中的应用连接配置 > 默认值。
- 自动生成并持久化 instance/secret.key；仅将应用连接凭据载入 Flask 配置，不载入 root 密码。
- 请求级 PyMySQL 连接；utf8mb4、+08:00、严格模式、autocommit=False；业务事务显式提交/回滚，拒绝嵌套事务，请求结束回滚未提交内容并关闭连接。
- 统一 JSON 响应 {code,message,data}；成功 code=0；业务、HTTP、数据库和未知异常均返回 JSON，错误响应不泄露内部异常内容。
- JSON 时间输出 +08:00；BIGINT 的字符串映射由后续各业务数据接口负责。
- 明确的跨域来源白名单，允许 Authorization、Content-Type、Idempotency-Key；错误响应也带相同跨域规则。
- 本地轮转日志 instance/logs/app.log；Waitress 运行入口，关闭 Flask 调试重载；仅监听 127.0.0.1:5000。

图片上限配置为单文件 2 MiB；请求体额外预留 multipart 元数据空间，具体文件大小与内容校验在步骤 5 实现。

## 运行方式

在 houduan 目录打开 PowerShell：

```powershell
.\scripts\start_backend.ps1
```

该入口先确保本项目 MySQL 运行，再在当前终端启动 API。按 Ctrl+C 停止 API，MySQL 仍保持运行；需停止数据库时执行：

```powershell
.\.venv\Scripts\python.exe .\scripts\local_mysql.py stop
```

也可以单独启动 API：

```powershell
.\.venv\Scripts\python.exe .\scripts\run_server.py
```

运行目录不影响应用内路径解析。根目录 .env.example 可按需复制为 .env；当前无需额外填写数据库密码，应用会读取现有本机配置。真实 .env、签名密钥和数据库密码不提交版本库。

## 当前接口

| 接口 | 用途 | 成功响应 |
| --- | --- | --- |
| GET /api/health | 判断 API 进程可用，不依赖数据库 | code=0，data.status=ok |
| GET /api/health/ready | 实际连接 MySQL 执行 SELECT 1 | code=0，data.status=ready |

这两个接口为运维检查接口，不计入交接包 20 个业务接口。当前访问网站根路径返回统一 JSON 404；页面和登录接口尚未开发。

## 验证方式与范围

```powershell
$env:RUN_DB_TESTS='1'
.\.venv\Scripts\python.exe -m pytest -q --basetemp=instance/pytest-check
.\.venv\Scripts\python.exe -m pip check
```

6 项测试覆盖健康检查、HTTP/业务/未知异常、JSON 格式和时区、跨域、签名密钥持久化与 root 配置隔离、数据库故障响应，以及真实数据库事务回滚、连接设置、嵌套事务拒绝和连接释放。数据库测试插入的探针用户在事务内回滚，不留存业务数据。

真实数据库测试需进程具备本机网络权限。首次受限环境中的数据库连接被拒绝，取得本机连接权限后测试通过。原有 17 项数据库测试结果见 database-verification-results.json。

本次最终结果：6 passed；pip check 无依赖冲突。Waitress 实际 HTTP 验证中，健康和数据库就绪接口均返回 200/code=0；不存在接口返回 404 JSON，允许来源的跨域头正常。API 当前已在本机后台运行。
